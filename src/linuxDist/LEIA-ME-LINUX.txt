SIMULAFISICA 3D - VERSAO LINUX

Como abrir sem IntelliJ ou VS Code:

1. Extraia a pasta SimulaFisica3D-linux-x64.
2. Clique duas vezes em SimulaFisica3D.desktop ou SimulaFisica3D.sh.
3. Se o Linux perguntar, permita executar como programa.

Se o arquivo nao abrir com duplo clique, marque como executavel:

   chmod +x SimulaFisica3D.sh
   ./SimulaFisica3D.sh

Se nao abrir por falta de Java:

- Instale Java 21 no Linux; ou
- Coloque um JDK 21 Linux portatil dentro desta pasta com o nome runtime.

O caminho esperado para Java portatil e:

   SimulaFisica3D-linux-x64/runtime/bin/java

O pacote ja inclui as bibliotecas JavaFX para Linux. Nao precisa abrir IDE.

Dica: para abrir direto em um modulo, rode no terminal:

   ./SimulaFisica3D.sh --module=solar_system
   ./SimulaFisica3D.sh --module=projectile

Modulos disponiveis: free_fall, projectile, collisions, inclined_plane,
pendulum, spring, solar_system, tug_of_war.

As missoes de foguete entre planetas ficam dentro do modulo solar_system:
escolha o modelo do foguete, o planeta de partida e o de destino.
